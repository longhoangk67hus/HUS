# Figma Design Project

## Project Goals & Objectives

### 1. Project Goal
The main goal of this project is to create a complete Figma design system for the website, encompassing all user states and roles. This design system helps to:

- Ensure an intuitive and consistent user experience.
- Provide a foundation for front-end and back-end development.
- Store both the initial design and the latest updates, facilitating version management.
- Clearly illustrate functional flows, tasks, and user behavior for each role.

---

### 2. Objectives

#### 2.1. Unauthenticated
**Goal:** Provide an engaging experience for new users or visitors, guiding them through the registration or login process.

**Objectives:**
- Display a homepage showcasing products/services with a clear and intuitive layout.
- Provide easily recognizable registration and login buttons.
- Provide basic information about the system, its features, and benefits.

**Functional Flow Description:**
- Access homepage → select registration → complete registration → log in.
- Access homepage → click on the login request function → display a message.

**User Task Description:**
- View website information.
- Register a new account.
- Log in.
- Receive notifications when operations are incorrect or unauthorized.

---

#### 2.2. Logging in as a User
**Goal:** Allow regular users to interact with the system, perform basic tasks, and access personal information.

**Objectives:**
- Display the personal dashboard after logging in.
- Provide a product/service list page, product details, transaction history, and personal settings page.

**Functional Flow Description:**
- Login → Dashboard → select product → view details → perform action (buy, order, register…).
- Search and filter products/services.
- Manage personal information: update profile, change password.

**User Task Description:**
- Access and edit personal information.
- Search, filter, and interact with products/services.
- Perform transactions or tasks on the system.
- Configure personal settings and notifications.

---

#### 2.3. Logging in as Admin
**Goal:** Provide administrators with the ability to manage the entire system, users, and data.

**Objectives:**
- Display a comprehensive administration dashboard with key statistics.
- Provide user management, content/product management, reporting, and system configuration pages.

**Functional Flow Description:**
- Login → Dashboard → User Management → Content Management → Statistics → Reporting.
- Approve or process user requests.

**Admin User Task Description:**
- Manage user accounts: add, edit, delete.
- Manage products, services, and displayed content.
- View and export system reports.
- Configure system settings and parameters.

---

### 3. Summary
The Figma folder stores all screens, functional flows, and user tasks for three states: logged-out, user, and admin.

These designs serve programmers, designers, and project managers to ensure accurate, intuitive, and efficient system development.

This document provides clear guidance for referencing user interfaces, flows, and behavior.
